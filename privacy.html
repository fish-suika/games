プライバシーについて

収集しない情報

このサイトでは、アクセス解析ツール、広告、Cookie、問い合わせフォームを使用していません。制作者が個人情報を取得することはありません。

配信元（GitHub Pages）について

このサイトは GitHub Pages で配信されています。サイトの閲覧時に、配信元の GitHub がアクセス記録（IP アドレスなど）を取得する場合があります。詳しくは GitHub のプライバシーステートメント をご確認ください。

外部サービスからの読み込み

一部のゲームは、プログラムの部品（three.js など）を cdnjs（Cloudflare が運営）から、文字のフォントを Google Fonts から読み込んでいます。読み込みの際、これらのサービスにアクセス記録（IP アドレスなど）が送られる場合があります。詳しくは各サービスのプライバシーポリシーをご確認ください。

ブラウザへの保存

一部のゲームでは、ハイスコアやベストタイム、設定などを、お使いのブラウザ内の保存領域（localStorage や IndexedDB）に保存することがあります。これらのデータはお使いの端末内にのみ保存され、外部へ送信されることはありません。

保存されたデータは、ブラウザの設定にある「サイトデータの削除」や「閲覧履歴データの削除」から消すことができます。
